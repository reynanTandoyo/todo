## Decision

After todo is updated, the first write command moves TODO.md to the new format in that same write, under the lock and after the usual snapshot; if the migrated text does not parse, nothing is written. Read commands understand every older format and never write. The rules block in AGENTS.md, the Claude Code skill and the hooks are brought up to date only by todo migrate --yes, and only where they are already installed; summary shows a reminder until then. (Owner, 2026-11-18)

## Reason

After an update each TODO.md must move to the new format without hand edits and without losing a byte. A simple note command must not rewrite AGENTS.md silently.

## Rejected

Migrating on read; updating AGENTS.md, the skill and the hooks automatically on any write.
