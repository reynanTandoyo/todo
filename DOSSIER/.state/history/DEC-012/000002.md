## Decision

Every command takes --json and then prints exactly one JSON object: schema, ok, data or error, warnings. Exit codes are fixed: 0 done, 1 refused by a rule, 2 wrong usage, 3 busy so try again, 4 file problem, 5 a check could not run. Error codes are stable names that never change meaning.

## Reason

Agents parse one stream and branch on the exit code; with one error code for everything an agent cannot tell "someone else has it" from "try again".
