## Assumption

The level the planner gives a task matches how hard the task is for a worker.

## Reason

The planner rates its own tasks and tends to be optimistic; todo checks only that the detail is there, not that it is right. The real test is whether workers give tasks back.

## Affects

todo plan, todo next --max-difficulty, every level-1 task
