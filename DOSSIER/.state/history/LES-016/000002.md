## Statement

Text with backticks, double quotes or a dollar sign is changed inside PowerShell double quotes. Use single quotes, or the - and @path forms.

## Valid for

Windows PowerShell 5 and PowerShell 7; any command that takes free text.

## Evidence

FND-041; requirement R-WRITE-12
