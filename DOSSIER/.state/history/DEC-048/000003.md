## Decision

A task's verify field holds one command line that todo runs itself. With verify_when = "done", done runs it first and refuses with VERIFY_FAILED when it fails; after three failures the task is given back. With verify_when = "wave", workers finish without the check and the planner runs todo verify --wave when the wave is finished; a task that fails is reopened and given back. The command is stopped after 300 seconds, verify = false turns running off, and skipping one check needs --force and leaves a note. Besides git, the editor of todo edit and the program that opens the report, this is the only kind of command todo runs. (Owner, 2026-11-19)

## Reason

Weak models report success when the work is broken, and asking the worker whether its test passed relies on the one thing that cannot be trusted. Wave mode exists because in a compiled project one worker's half-finished edit breaks the build for every other worker's check.

## Rejected

Trusting the worker's word; running the full test suite at every done.
