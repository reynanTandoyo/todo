## Decision

Fixtures in tests/fixtures are small and invented, and each starts with the TEST FIXTURE line. A real task list is never copied into this repository. Tests run the built todo.exe in temporary folders, with TODO_FILE, TODO_AGENT and the register variables removed, and never read or write this repository's own TODO.md. .gitattributes keeps fixture line endings exactly as written.

## Reason

The earlier projects' task lists are private, and a test that reads the real TODO.md gives different results on every machine.
