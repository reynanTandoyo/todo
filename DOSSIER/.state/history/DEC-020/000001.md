## Decision

TODO.md is UTF-8 only. Each line keeps its own line ending, and bytes the tool does not change stay identical. The file is never rebuilt from parsed data: commands replace, insert or remove whole lines, and before writing the tool checks that every byte outside the changed lines equals the original. Reading is lenient, writing is canonical only on lines the tool changes.

## Reason

Files edited on Windows mix line endings, and preserving bytes is what makes the tool safe to use on hand-written files. One earlier script rewrote every line ending on each write.

## Rejected

Strict parsing with a canonical rewrite of the whole file: it drops unknown keys and turns CRLF into LF.
