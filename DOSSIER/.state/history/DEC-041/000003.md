## Decision

When the format line names a version the running tool does not know, every command that reads or writes tasks refuses with exit 4 and TOOL_TOO_OLD, names the version stamped in the file and says to update the executable first. The format version is raised whenever an older tool would misread the file: version 2 in v0.6 (milestones, ideas), version 3 in v0.8 (levels, steps, file scopes). (Owner, 2026-11-18)

## Reason

An old todo that half-understands a newer file would hand out milestones or ideas as ordinary tasks. The owner wants it to stop and ask for an update instead of only warning.

## Rejected

Reading a newer format with a warning, as todo did up to 0.5.
