## Decision

One TODO.md per repository. Tasks are blocks that start with a heading such as "### T-012 · Title", with one "- key: value" line per field, under free-form "##" sections (docs/format.md).

## Reason

One file stays readable in any editor and on GitHub and can be protected by one lock. The block format gives stable IDs, room for fields and one-line diffs, and it handled 375 tasks in practice in an earlier project.

## Rejected

One file per task: harder to read, needs a generated index and ID allocation across branches. Checkbox lines: no stable IDs and the whole long line changes in a diff. Supporting both layouts: two of everything. (docs/research.md section 3)
