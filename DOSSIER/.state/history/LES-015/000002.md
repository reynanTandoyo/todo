## Statement

When the owner corrects the meaning of something, write it as a note on every task it affects, with the owner's own example, before any worker starts. The note "a milestone is a piece of work such as Develop the renderer, never a release label" kept every later task and fixture on that meaning.

## Valid for

Plans whose tasks are built later by other agents that never saw the conversation.
