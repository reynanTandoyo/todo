# Glossary of TODO

## entry

- meaning: One block in TODO.md that starts with a heading such as "### T-012 · Title". Every entry has one kind: task, milestone, question or idea.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## task

- meaning: An entry that is work for one agent. It has a status, a priority and a level, and next hands it out.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## milestone

- meaning: A piece of work with a goal, divided into tasks or further milestones, such as "Develop the renderer". It is an entry of type milestone, is never a release label, and is never handed out or closed automatically.
- also: goal
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## question

- meaning: An entry of type question that only a person can answer; next never hands it out, and answer closes it.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## idea

- meaning: An entry of type idea: recorded so it is not lost, but not work until promote turns it into a task.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## status

- meaning: One of five: open, claimed, blocked, done, dropped. The status page for people calls them to do, in progress, waiting, done and cancelled.
- also: state
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## claim

- meaning: An agent takes a task: status claimed, the owner and the claim time are written. A second agent is refused.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## stale claim

- meaning: A claim older than claim_ttl_hours (24 by default). Another agent may then take the task over, and a note records it.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## write lock

- meaning: The operating-system file lock every write command holds while it reads, changes and replaces TODO.md. The system frees it when the process ends.
- also: lock
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## lease

- meaning: A manual lock of 10 minutes by default that a person or agent takes with todo lock to edit TODO.md by hand; other writers wait.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## state folder

- meaning: The folder with the lock, lease, snapshots, journal and ID record of one TODO.md: .git/todo/<path> inside git, shared by all worktrees and never committed, or .todo next to the file outside git.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## snapshot

- meaning: A numbered copy of TODO.md saved before each write; history lists them, diff compares them and restore puts one back.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## journal

- meaning: A file of JSON lines in the state folder with one line per write: time, agent, command, tasks and the hash before and after.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## archive

- meaning: TODO-archive.md next to TODO.md. todo archive moves done and dropped entries there; a milestone tree moves only as a whole.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## managed block

- meaning: The lines between the todo:begin and todo:end markers in AGENTS.md or TODO.md. They hold the rules text and belong to the tool; agents install replaces only them.
- also: rules block
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## combined priority line

- meaning: One field line that holds several fields separated by a middle dot, such as "- priority: P1 · type: bug · area: ui".
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## tool stamp

- meaning: The line "todo-tool: x.y.z" under the format line of TODO.md: the highest todo version that has written the file. It is only ever raised.
- also: stamp
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## format version

- meaning: The number in the first line of TODO.md. A tool that does not know the number refuses the file and asks for an update.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## migration

- meaning: The step that moves a TODO.md to a newer format version. It runs by itself on the first write of a newer todo, under the lock and after a snapshot.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## level

- meaning: The difficulty of a task, 1 to 5: how much of the work is still open. Level 1 means everything is written down, so the weakest agent finishes it without a mistake.
- also: difficulty
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## target level

- meaning: The level the planner splits down to (target_difficulty, by default the lowest). Tasks at or below it need complete detail.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## planner

- meaning: The role of one strong agent: plans milestones and tasks, gives levels, splits and details tasks until todo plan is empty, reads the waves and takes back tasks given back.
- also: coordinator
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## worker

- meaning: The role of any coding agent that takes a level-1 task with its work order, changes only its files, commits and finishes with todo done, or gives it back with todo stuck.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## work order

- meaning: The one text todo brief prints for a worker: the goals above the task, the why, the files to read and to change, the steps, the check and the commands to finish or give up.
- also: brief
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## ready

- meaning: A task at the target level is ready when it has why, accept, steps, verify and files. next hands out only ready tasks.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## verify command

- meaning: The one command line in a task's verify field. todo runs it at done, or for all tasks of a finished wave, and refuses done when it fails.
- also: check
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## given back

- meaning: A task a worker could not finish and returned with todo stuck: it is blocked, has no owner, and carries the problem as a note for the planner.
- also: stuck
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## file scope

- meaning: The files field of a task: the paths and patterns it may change. next never hands out two tasks whose scopes overlap, and done checks that the commit stayed inside.
- also: files
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## wave

- meaning: A group of tasks that can run at the same time. Wave 1 is everything ready now; wave n becomes ready when the waves before it are done.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## lane

- meaning: Tasks of one wave that share a file and so must run one after another.
- history: 2026-11-26T19:44:46+01:00 reyna via reyna - claude fable 5.2: added

## final

- meaning: A field with the reason why a task is kept above the target level on purpose, as the planner's last resort.
