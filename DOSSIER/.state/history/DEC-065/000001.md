## Decision

todo does not do these: due dates, recurrence and computed priority scores; other record types such as decision records, plans or issues (milestones, questions and ideas are kinds of entry in TODO.md); syncing with GitHub Issues, Jira or other trackers; locking across machines or real-time sync, because git handles sharing between machines; changing a status automatically; macOS builds, an installer and code signing. (docs/requirements.md section 13)

## Reason

These belong to personal to-do tools or to trackers, not to a task list that agents share inside one repository; each would add a dependency, a network connection or a second source of truth.

## Rejected

Due dates and recurrence as in a personal task manager studied; a generated board; sync between machines field by field.
