## Assumption

Every agent and person that writes to one TODO.md at the same time works on the same PC, and the file is not in a folder synced by OneDrive or Dropbox.

## Reason

The operating-system lock protects one machine only; between machines git and the merge driver do the sharing. A synced folder only gets a warning.

## Affects

limits.lock-wait, the write lock, claims
