## Decision

Command names and options, JSON schemas (todo.<command>.v1), error codes, exit codes and the file format are interfaces that agents and scripts rely on. A breaking change needs a new major version and an entry in CHANGELOG.md; the file format has its own version line. New error codes may be added; existing ones never change meaning. (NFR-8)

## Reason

Agents branch on exit codes and parse the JSON; a silent change would break every project that uses the tool.
