## Decision

Each write command takes an operating-system file lock for the time it reads, changes and writes the file. A person or agent editing by hand takes a lease with todo lock, 10 minutes by default and 60 at most. Read commands never take the lock.

## Reason

The operating system frees the lock when a process dies, so a crash never blocks the others. Replacing the file in one step makes reading without a lock safe.

## Rejected

Lock folders or lock files that must be broken after a timeout, as in the earlier scripts: each script only saw its own kind of lock.
