## Decision

Windows 10 and 11 x64 is the target platform. Linux is built and tested in CI to keep the code portable, and a Linux binary is released. There are no macOS builds. Paths with spaces, non-ASCII characters and more than 260 characters must work; examples are shown in PowerShell.

## Reason

The tool is wanted as a Windows .exe; Linux CI is cheap; nothing is available to test macOS.

## Rejected

macOS builds.
